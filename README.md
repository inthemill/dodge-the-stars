# Noes Programmier-Setup

Dieses Projekt ist ein einfaches Lernprojekt mit p5.js.

## So startest du

1. Öffne den Ordner in VS Code.
2. Öffne die Datei `index.html`.
3. Klicke unten rechts in der Statusleiste auf **Go Live**.
4. Das Spiel wird dann im Browser geöffnet.

## Was du hier lernst

- HTML anlegen
- JavaScript schreiben
- p5.js verwenden
- Spielelemente bewegen
- Punkte zählen
- Einfaches Spiel-Design verstehen

## Aufgaben fuer Noe
